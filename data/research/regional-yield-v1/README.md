# Regional yield preparation audit

The prepared default Atlas dataset is `shared/data/regional-yield.json`, with an
identical browser fallback at `apps/web/public/data/regional-yield.json`.
`validation.json` records source/archive hashes, per-file digests, count/geometry
checks, thresholds and interpretation limits. Original large archives and raw
sample files are not stored here.

See [regional Atlas documentation](../../../docs/REGIONAL-ATLAS.md) and the
[independent review](../../../docs/REGIONAL-ATLAS-REVIEW.md) for provenance,
reproduction, geographic coverage and limits. This is a county summary of published
historical model outputs, not a new model, an H3 forecast or financial data.
