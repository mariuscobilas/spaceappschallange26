# Preview geography

`conus.geojson` contains the contiguous US polygon extracted from Natural Earth's
1:110m Admin 0 countries dataset (public domain):
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

This generalized coastline supports offline orientation and illustrative H3
coverage. It is not parcel geometry or a cropland classification.

`../../data/benchmark_farms.json` contains locality reference coordinates, not
surveyed farm locations. The six Kansas locations are preview navigation targets.
Risk values in the map are deterministic synthetic examples, not agronomic advice.
